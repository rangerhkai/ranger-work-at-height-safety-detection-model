The **RANGER™ Work at Height Safety Detection Model** is a YOLO-based object detection model for identifying Work at Height Safety in construction scenes.

It is designed with real-site imagery in mind and may be used as a starting point for research, teaching, internal testing, and non-commercial proof of concept.

**RANGER™ Work at Height Safety Detection Model** 是一套基於 YOLO 的物件偵測模型，用於識別建造場景中的高處工作安全（Work at Height Safety）項目。
